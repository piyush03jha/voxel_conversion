# Worker

Existing ADVFX import routes plus modular single-file exporters. The shared compatibility matrix selects 188 candidate pairs across the original 15 formats; content and resource limits apply. GLB uses native/Blender import and glTF Transform; other scene targets use direct Blender export, embedded GLTF is generated from GLB, and vector routes use Poppler/librsvg. Static mesh and 3MF compression are available where supported. Custom color is paused. One job per replica. See docs/phase-3.md, docs/phase-4a.md and docs/phase-5.md.
