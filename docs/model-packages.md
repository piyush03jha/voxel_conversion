# Model packages (v7 worker contract)

Single model folder: /package or /compress/package. ZIP and folder selection preserve paths. One detected root is selected automatically; several candidates require choosing the primary model. Batch workspaces still allow independent roots to be selected individually. Supporting files are shown per root.

OBJ: MTL, standard map options, relative texture references. glTF/GLB: external BIN/image URIs (GLB JSON chunk scanned). ASCII USD: recursive common @asset@ layer references, referenced layers are not treated as independent roots. Binary USD and FBX: include assets from the chosen top-level folder; importer-dependent, opaque references must resolve and external paths may need relinking. No DAE support. Nested USDZ references inside USD folders are rejected; standalone USDZ and 3MF remain single model packages. Unrecognized references and missing files fail or are reported rather than silently converting dependencies as independent jobs.

Package export: OBJ, USD, USDA, USDC use a ZIP with model and supported material/texture files. GLB/FBX/GLTF/USDZ keep their existing self-contained outputs where supported. Blender export uses COPY for OBJ, NEW/relative texture paths for USD; OpenUSD resolves layers and assets in the sandbox and rejects unresolved/outside paths. Static geometry formats cannot retain full materials. Existing single-file route still produces geometry-only OBJ/USD; choose package route for material export.

Package compression: same-format lossless ZIP repacking (Low/Medium/High = deflate 1/6/9), no model, texture, or geometry rewrite. Size is measured against the browser's stored ZIP of selected model/dependency bytes, not the compressed size of the user's original archive. Original stored package retained if no smaller result or expansion-ratio checks fail. It is not lossy mesh/texture optimization. Standalone supported compression routes unchanged. Folder expansion/worker archive budget remains finite; no fixed standalone upload-size cap.

Package preview: explicit low-priority geometry preview imports the whole package, reuses the same batch's owner token, and retains source session. Conversion can copy the verified temporary source on storage without re-uploading from browser. ETag and size checked; distinct keys/retention preserve isolation. Storage copy duplicates object temporarily and is provider-limited (single-copy limits, expiry); retry with fresh upload if reuse fails. This is not reference-counted zero-copy storage. Output ZIP preview imports the recorded primary path. Preview is approximate static geometry, not a material fidelity viewer. No conversion blocked on optional preview unless user requests preview first. Source retained until standard expiry. No changes to ADVFX.
