# Preview for all existing input and output formats

All fifteen existing formats have a preview route. STL/OBJ/PLY/GLB/GLTF keep the browser-first geometry preview for eligible files, with an explicit server preview option for unsupported content or larger models. FBX, 3MF, USD, USDA, USDC, USDZ, ABC and BVH use the existing Blender importer to create a small static geometry GLB. PDF and SVG use a raster PNG (PDF first page), rather than executing SVG markup in the browser. Input preview never alters the conversion output.

Server preview is optional and explicitly initiated by the user. Input or local output is uploaded via a signed URL, with purpose=preview, fixed GLB logical target and None compression. For a completed server output, POST /api/jobs/:id/preview authenticates the parent token and copies its output in private storage into a separate preview session; no browser re-upload. The child uses its own queue reservation, token and object keys. PDF/SVG preview artifacts are PNG; the format is reported as previewKind. Both use the existing owner-only status and signed download endpoints. Preview jobs have lower priority than normal conversions and consume the same admission/rate limits, one job per worker. Priority jobs show waiting status but do not have a regular FIFO position or ETA. Preview jobs do not contribute duration samples to conversion ETA.

Preview geometry is a static first/current-frame representation, at most 100,000 sampled triangles, 512 mesh instances, 8 million source triangles, finite world-space coordinates, no textures, materials or animation. Sampling may omit details or produce holes. PNG max dimension 1200 px. Maximum preview artifact 10 MiB, generation deadline 120 seconds; existing conversion resource limits still apply. Input limit 200 MiB does not guarantee preview success. Invalid, unsupported, dependency-missing or oversized content can fail gracefully. Local preview still runs in a bounded Web Worker. Output preview may require GET CORS on the temporary bucket. No extra persistent storage or dependencies. Active preview jobs cannot be forcibly cancelled; stop tracking attempts queued cancellation, and abandoned data expires normally. After the UI fetches a completed preview, it releases the preview job using the authenticated cancellation endpoint; finished preview jobs can be removed without affecting normal conversion jobs. Objects are deleted by the existing sweeper after the signed upload expiry/grace period. Abandoned jobs retain the existing retention window and bucket lifecycle fallback.

## Verify before deployment
Restart API and workers together (heartbeat v4). Test each of the 15 input formats, then completed outputs, including server copy in R2/MinIO, document raster output, malformed inputs, large models, priority scheduling, cancellation, storage expiry and privacy. Test with trusted local fixtures only until production sandbox is verified. No live Blender, Docker or full build verification has been performed in the authoring environment.
